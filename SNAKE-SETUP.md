# 🐍 Snake Game Setup Instructions

## Quick Setup (3 steps):

### 1. Enable GitHub Pages
- Go to your GitHub repository settings
- Scroll to "Pages" section
- Under "Source", select "GitHub Actions"

### 2. Push your code
```bash
git add .
git commit -m "Add interactive Snake game to profile"
git push origin main
```

### 3. Update README links
After GitHub Pages deploys (2-3 minutes), replace `subh-a-dip` in the README with your actual GitHub username:
- Change `https://subh-a-dip.github.io/snake-game.html` 
- To `https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/snake-game.html`

## That's it! 🎉

Your visitors can now play Snake directly in your GitHub profile!
