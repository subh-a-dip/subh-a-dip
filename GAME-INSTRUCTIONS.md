# 🐍 Snake Game - How to Play

## 🚀 Quick Start

### Option 1: Windows (Easy)
1. Double-click `start-game.bat`
2. Game will open automatically in your browser
3. Click "🎮 Start Game" to play!

### Option 2: Manual Start
1. Open terminal/command prompt in this folder
2. Run: `python server.py`
3. Open browser and go to: `http://localhost:8000/snake-game.html`

## 🎮 Game Controls

### Desktop
- **Arrow Keys**: ↑ ↓ ← → to control snake
- **Goal**: Eat red apples to grow and score points
- **Avoid**: Hitting walls or yourself

### Mobile
- **Touch Buttons**: Use on-screen arrow buttons
- **Responsive**: Game adapts to mobile screens

## 🛠️ Technical Details

- **Built with**: HTML5 Canvas, CSS3, JavaScript
- **Server**: Python HTTP Server
- **Port**: 8000 (default)
- **Features**: Mobile responsive, touch controls, smooth gameplay

## 🔧 Troubleshooting

- **Port in use**: Change PORT in `server.py` to different number (e.g., 8001)
- **Python not found**: Install Python from python.org
- **Game not loading**: Check if server is running and visit correct URL
